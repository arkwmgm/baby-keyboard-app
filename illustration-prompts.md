## 📁 ファイル命名規則

生成後のファイル名は以下の規則で保存してください：

```
assets/
  animals/
    cat.png
    dog.png
    frog.png
    ...
  flowers/
    cherry-blossom.png
    hibiscus.png
    ...
  vehicles/
    car.png
    airplane.png
    ...
  sea/
    clownfish.png
    octopus.png
    ...
  dogs/
    shiba.png
    poodle.png
    ...
  food/
    apple.png
    pizza.png
    ...
```

HTMLで使う際は絵文字を `<img>` タグに置き換えるだけでOKです：
```js
// 現在
el.textContent = '🐱';

// イラスト化後
el.innerHTML = `<img src="assets/animals/cat.png" style="width:${size}px;height:${size}px;">`;
```
